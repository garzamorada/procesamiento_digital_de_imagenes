### 09.0_filtros_activaciones.ipynb

**Descripción:**
Este cuaderno busca desmitificar las **Redes Neuronales Convolucionales (CNNs)** mediante la visualización de cómo sus capas internas procesan las imágenes. Demuestra cómo obtener una comprensión intuitiva de su aprendizaje al explorar los **filtros (kernels)** aprendidos y los **mapas de características (activaciones)** generados. El laboratorio construye y entrena una CNN simple en el dataset MNIST (dígitos escritos a mano) y concluye con un glosario de términos clave.

**Puntos Clave:**
* Desmitificación de CNNs mediante visualización.
* Exploración de filtros aprendidos y mapas de características.
* Implementación y entrenamiento de una CNN con el dataset MNIST.
* Glosario de términos relevantes de CNNs.

### 09.1_cnn_básica_con_keras_y_tensorFlow.ipynb

**Descripción:**
Este cuaderno proporciona una guía didáctica para profundizar en los fundamentos de las **Redes Neuronales Convolucionales (CNNs)**. Utilizando Keras (como API de alto nivel) y TensorFlow (como backend), desarrolla y entrena un modelo capaz de clasificar imágenes de prendas de vestir a partir del popular dataset Fashion MNIST. El material ofrece tanto la fundamentación teórica indispensable como la implementación práctica detallada. Incluye un glosario de términos técnicos.

**Puntos Clave:**
* Fundamentos de las CNNs.
* Clasificación de imágenes usando Keras y TensorFlow.
* Aplicación con el dataset Fashion MNIST.
* Guía didáctica con teoría e implementación práctica.
* Glosario de términos relacionados con CNNs y Keras/TensorFlow.

### 09.2_cnns_full.ipynb

**Descripción:**
Este cuaderno sirve como una introducción a las **Redes Neuronales Convolucionales (CNNs)**, destacando su eficacia para el procesamiento de imágenes en tareas como reconocimiento facial, clasificación y detección de objetos. Está pensado con fines pedagógicos para estudiantes de Procesamiento Digital de Imágenes, explorando cómo se construye, entrena y evalúa una CNN utilizando un dataset estándar.

**Puntos Clave:**
* Introducción a las CNNs y sus aplicaciones en procesamiento de imágenes.
* Proceso de construcción, entrenamiento y evaluación de una CNN.
* Orientado a la enseñanza y el aprendizaje de CNNs.
* Utiliza TensorFlow y TensorFlow Datasets.

### 09.3_gemini2_espacial.ipynb

**Descripción:**
Este cuaderno, traducido al español por Matías Barreto, se enfoca en la **comprensión espacial 2D utilizando Gemini 2.0**. Guía al usuario a través de la instalación del SDK de `google-genai` para acceder a la API de Gemini. Además de la comprensión espacial, el cuaderno enlaza a otros ejemplos del "cookbook oficial" de Gemini 2.0, como la API en vivo, comprensión de video, y aplicaciones de marketing, ofreciendo una visión amplia de sus capacidades.

**Puntos Clave:**
* Introducción a la comprensión espacial 2D con Gemini 2.0.
* Instalación y uso del SDK de Google GenAI.
* Referencias a otros ejemplos de las capacidades de Gemini 2.0 (API en vivo, video, etc.).
* Ejemplos de uso del modelo Gemini para inferencias espaciales.
